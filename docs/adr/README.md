# Architecture Decision Records (ADR)

ADRs registram decisões arquiteturais **importantes e duradouras**: contexto, alternativas, decisão e consequências.

Nenhum ADR numerado foi extraído automaticamente desta reorganização. Decisões de alto nível e componentes ainda não implementados continuam descritos em [`../architecture/overview.md`](../architecture/overview.md).

Novos ADRs devem seguir o padrão `NNN-titulo-em-kebab-case.md` (por exemplo, `002-use-pessimistic-locking-for-stock.md`).
